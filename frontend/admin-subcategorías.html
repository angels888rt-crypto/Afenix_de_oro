Subcategorías de Platos

Crea, edita y elimina subcategorías. Cada subcategoría representa una característica adicional (ej. Color del arroz, Tamaño, Nivel de picante) que se aplica a platos específicos.

Crear subcategoría

Define una característica adicional para platos. Ejemplo: Color del arroz, Tamaño, Nivel de picante.

Opciones de la subcategoría

Define las opciones disponibles. Ejemplo: Amarillo, Café, Blanco.

Selecciona los platos a los que se aplicará esta subcategoría.
